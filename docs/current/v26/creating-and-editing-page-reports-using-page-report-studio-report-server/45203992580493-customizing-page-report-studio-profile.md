# 
Customizing Page Report Studio Profile

You can configure the preferences and features of Page Report Studio by profile on the Server Console. This topic describes how you can customize Page Report Studio profile properties.

This topic contains the following sections:

- Server Administrators

- Any Users

## 
Server Administrators

You can navigate to the Administration > Server Profile > Customize Profile > Page Report Studio tab on  the Server Console, create different profiles for end users to choose, set the default profile, and edit/remove the  profiles you created.

Server provides the Default profile which enables all the Page Report Studio features. You can create different profiles with different features to serve for different purposes. To create a new profile, select New Profile. Then, in the  Page Report Studio Profile dialog box, define the features you want for the profile.

To set a default profile, select a profile from the Default Profile drop-down list. Server displays the Default profile and all other profiles that you have created in the drop-down list for your selection.

By selecting a profile name in the Name column, you can view the profile settings in the Page Report Studio Profile dialog box.

For the profiles that you created, you can edit them by selecting Edit and then making changes in the  Page Report Studio Profile dialog box. 

You can remove a profile if you no longer want it, select it in the profile table, then select Delete.

You cannot change or delete the Default profile.

## 
All Users

You can navigate to the My Profile > Customize Profile > Page Report Studio tab on  the Server Console,  set the default profile, or customize the profile for Page Report Studio.

To set a default profile, select a profile from the Default Profile drop-down list. Server displays the Default profile and all other profiles that server administrators have created in the drop-down list for your selection.

If you don't want to use any of the existing profiles, you can customize the profile for Page Report Studio. 

- Select Customize Profile. Server displays the Customize Profile dialog box.

- Select Enable Customize Properties.

- Change the settings on the Common and Page Report Studio tabs as you want. Here you can also update the settings for Web Report Studio and JDashboard.

- Select OK. Server applies your customized profile settings instead of the default profile you selected.
