# 
Getting Started with Report Server

This topic guides you through the process of installing and configuring Report Server, running and creating reports and dashboards in Report web editors, and distributing reports to a variety of outputs.

1. Product Installation
- Think about the number of Report servers you need if you want to set up a Report Server Cluster. See Report Server Cluster.

- Decide the licensed features that you want for each Report server. See Report Licenses.

- Prepare the computers on which you want to install Report Server. See Report Server System Requirements.

- Obtain the Report Server install program. Also obtain the Report Server Monitor install program if you want a Server Monitor. See Report download center.

- Install Report Server using the way you prefer. See Installing and Uninstalling Report Server.

- Install Server Monitor if you want to monitor your server performance. See Installing and Uninstalling Server Monitor in the Report Server Monitor Guide.

2. Server Database Configuration for MetadataConfigure the server database for metadata on the Server Console or using the configuration file if you didn't do this during the installation. See Configuring Server Databases for Server Metadata in a Standalone Environment.

3. Product Security and Authorization
- Create security organizations to manage different groups of users. See Multitenancy Supported via Organizations.

- Set up user accounts, roles, and groups, with appropriate privileges. See Security System Data Model.

- Integrate with your security software, for example, LDAP. See Using an LDAP Server's Security System.

4. Resource Publish and Permissions
- Publish reports, catalogs, and library components to Report Server. See Publishing Resources.

- Set up user permissions on the server resources. See Managing Permissions.

- Optionally, obtain resources from the real path dynamically. See Getting and Using Resources From a Real Path.

5. Export Configuration
- Configure the email server if you want to deploy reports via email. See Configuring the Email Server.

- Configure settings for exporting reports to email and fax. See Configuring Export Settings.

6. Cluster SetupSet up a Report Server Cluster in which multiple servers work together. See Setting Up and Starting a Report Server Cluster.

7. Integration Setup
- Configure the server database. See Configuring Server Databases for Server Metadata in an Integrated Environment.

- Create the Report Server WAR/EAR. See Building a WAR/EAR File to Include a Self-contained Report Server.

- Deploy the WAR/EAR to an application Server. See Deploying Report Server to a Java Application Server.

8. Server Monitor

- Start and access the Server Monitor. See Launching and Accessing Server Monitor in the Report Server Monitor Guide.

- Monitor the status and performance of Server. See Using Server Monitor in the Report Server Monitor Guide.

9. Report Running and Scheduling
- Run reports directly or on demand. See Running Reports.

- Schedule tasks to run reports at the specified time to different locations in various formats. See Scheduling Reports.

10. Report Creating, Editing, and Exporting
- Create, edit, and export web reports using Web Report Studio. See Web Report Studio.

- Create, edit, and export page reports using Page Report Studio. See Page Report Studio.

- Create, edit, and export dashboards using JDashboard. See Introduction to the Report JDashboard.
