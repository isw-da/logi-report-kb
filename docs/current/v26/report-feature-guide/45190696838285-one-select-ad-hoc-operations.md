# 
One-Select Ad Hoc Operations

Report supports several one-select ad hoc operations, with which you can easily change the data presentation of a report and sort and filter the report data.

This guide explores the following one-select actions: 

- One-Select to Pivot Crosstab

- One-Select to Swap Group/Value in Chart

- One-Select to Sort and Filter Table

- One-Select to Drill Down Report Data

- One-Select to Convert Table/Crosstab/Chart

- Chart Zoom via Range Selection
