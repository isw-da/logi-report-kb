# 
Insert Summary Column Dialog Box Properties 

You can use the Insert Summary Column dialog box to insert a new summary column into a table. This topic describes the properties in the dialog box.

Resource

Server lists all the available data resources for the new summary column. Select the one you want. 

Insert Before

Select to insert the new summary column before the selected column. This property is available when you access the dialog box by right-clicking a table column.

Insert After

Select to insert the new summary column after the selected column. This property is available when you access the dialog box by right-clicking a table column.

Cancel

Select to close the dialog box without inserting a summary column.

OK

Select to insert the summary column into the report and close the dialog box.

Help button

Select to view information about the  dialog box.

Close button

Select to close the dialog box without inserting a summary column.
