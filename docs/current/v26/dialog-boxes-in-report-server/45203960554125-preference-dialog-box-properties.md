# 
Preference Dialog Box Properties

This topic describes how you can use the Preference dialog box to set preferences for the specified user. 

Server displays the dialog box when an administrator selects Preference of a user in the Control column of the Administration > Security > User page on the Server Console.

It contains two subjects: Customize Server Preferences and Customize Profile. You can specify the server preferences for the user as well as the Default and Advanced properties you want the user to use in Page Report Studio.
