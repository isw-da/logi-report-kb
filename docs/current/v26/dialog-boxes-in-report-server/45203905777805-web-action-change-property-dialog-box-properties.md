# 
Web Action - Change Property Dialog Box Properties 

Use the Web Action - Change Property dialog box to specify the properties to change their values for a data component when it receives a synchronization message. This topic describes how to change property values.

Server displays the dialog box when you select the web action *Property and then select the Edit button  in the Actions column of the Receive Sync dialog box.

Add button

Select to add a new property line.

Remove button

Select to remove the selected property line.

Properties

Select or type the property whose value you want to change. You can only change the properties of the data component itself. 

Value

Select the value of the property.

OK

Select to apply any changes you made here and close the dialog box.

Cancel

Select to close the dialog box without saving any changes.

Help button

Select to view information about the dialog box.

Close button

Select to close the dialog box without saving any changes.
