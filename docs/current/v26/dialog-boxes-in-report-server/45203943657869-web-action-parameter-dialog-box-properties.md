# 
Web Action - Parameter Dialog Box Properties 

Use the Web Action - Parameter dialog box to edit the parameter values to rerun a data component when it receives a synchronization message. This topic describes how to update parameter values.

Server displays the dialog box when you select the web action *Parameter and select the Edit button  in the Actions column of the Receive Sync dialog box.

Add button

Select to add a line to specify parameter values.

Remove button

Select to remove the selected parameter.

Parameter Name

Select a parameter that the data component uses or type the parameter name.

Operator

The operator of the expression. It can only be =.

Parameter Value

Select the value for the parameter.

OK

Select to apply any changes you made here and close the dialog box.

Cancel

Select to close the dialog box without saving any changes.

Help button

Select to view information about the dialog box.

Close button

Select to close the dialog box without saving any changes.
