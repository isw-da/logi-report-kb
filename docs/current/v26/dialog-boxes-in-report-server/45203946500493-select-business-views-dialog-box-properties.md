# 
Select Business Views Dialog Box Properties

This topic describes how you can use the Select Business Views dialog box to add or update the business views in the business view security in a catalog.

Server displays the dialog box when an administrator selects Select on the Business View Security tab of the Properties dialog box for a catalog.

Select Business Views

Server lists all the business views in the catalog. You can select multiple business views by selecting the corresponding checkboxes. 

All

Select to select all the business views in the catalog.

OK

Select to apply any changes you made here and close the dialog box.

Cancel

Select to close the dialog box without saving any changes.

Help

Select to view information about the dialog box.
