# 
Sign Dialog Box Properties

This topic describes how you can use the Sign dialog box to specify the PDF signing properties when configuring settings for advanced running/publishing a report in PDF. 

Method

Select a signing digital signature method from the three methods provided by Adobe Acrobat software.

Digital ID File

Select Browse, and then select a digital ID file from your local folder.

User Password

Specify the password for this digital ID file.

Confirm Password 

Type the password again to confirm it.

Reason for Signing Document

Select the reason for signing the document.

Or Other Reason

Provide another reason for signing the document.

Location

Edit your location accordingly.

Your Contact Information

Edit your contact information accordingly.

OK

Select to apply any changes you made here and close the dialog box.

Cancel

Select to close the dialog box without saving any changes.

Help

Select to view information about the dialog box.
