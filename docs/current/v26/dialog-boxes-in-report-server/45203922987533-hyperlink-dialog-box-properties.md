# 
Hyperlink Dialog Box Properties 

Use the Hyperlink dialog box to add a hyperlink on the selected object. This topic describes how to add URL.

Server displays the dialog box when you select the Hyperlink button  in the Edit HTML dialog box or Insert HTML dialog box. 

URL

Type the URL you want to direct the hyperlink to. 

OK

Select to add the hyperlink.

Cancel

Select to close the dialog box without adding a hyperlink.

Help button

Select to view information about the Hyperlink dialog box.

Close button

Select to close the dialog box without adding a hyperlink.
