# 
Zoom Dialog Box Properties 

You can use the Zoom dialog box to set a magnification of the report page. This topic describes the properties in the dialog box.

Zoom to

Specify the magnification in percentage.

OK

Select to apply any changes you made here and close the dialog box.

Cancel

Select to close the dialog box without saving any changes.

Help

Select to view information about the dialog box.
