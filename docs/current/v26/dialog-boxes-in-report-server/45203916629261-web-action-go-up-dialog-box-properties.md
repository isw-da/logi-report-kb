# 
Web Action - Go Up Dialog Box Properties 

Use the Web Action - Go Up dialog box to edit the go-up condition  to go up on a group of a data component when it receives a synchronization message. This topic describes how to define the go-up condition.

Server displays the dialog box when you select the web action *Go Up and select the Edit button  in the Actions column of the Receive Sync dialog box.

Go Up On

Select the group on which you want to perform the go-up action in the data component.

Use Hierarchy

Select the hierarchy that the go-up action will follow. 

OK

Select to apply any changes you made here and close the dialog box.

Cancel

Select to close the dialog box without saving any changes.

Help button

Select to view information about the dialog box.

Close button

Select to close the dialog box without saving any changes.
