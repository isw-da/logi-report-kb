# 
Comparison Function Dialog Box Properties

You can use the Comparison Function dialog box to add a comparison function as an aggregate field for a crosstab. This topic describes the properties in the dialog box.

Server displays the dialog box when you select Comparison Function in the Crosstab Wizard, Insert Crosstab dialog box, Convert to Crosstab dialog box, or To Crosstab dialog box, or in the Bind Data screen for crosstab in the Web Report Wizard.

Function

Select the function of the calculation: Percentage, Permillage, or Difference.

Comparison Function Spans on Row Direction

Select if you want to place the comparison function into the column total cell of the crosstab.

Comparison Function Spans on Column Direction

Select if you want to place the comparison function into the row total cell of the crosstab.

Break By

Select the first parameter of the comparison function.

Refer To

Select the other parameter of the comparison function.

OK

Select to apply any changes you made here and close the dialog box.

Cancel

Select to close the dialog box without saving any changes.

Help button

Select to view information about the dialog box.

Close button

Select to close the dialog box without saving any changes.
