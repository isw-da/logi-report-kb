# 
Suppress Column Subtotals Dialog Box Properties

This topic describes how you can use the Suppress Column Subtotals dialog box to customize the subtotals of the column fields in a crosstab that you want to suppress and display. 

Server displays the dialog box when you select the ellipsis button  next to Suppress Column Subtotals in the Layout tab of the Crosstab Wizard or Insert Crosstab dialog box, or in the Layout tab for crosstab in the Web Report Wizard. 

Same for all

Select if you want to apply the setting for the subtotal of the first column field to all the subtotals of the column fields in the crosstab. 

Name

Server lists the column fields excluding the one on the topmost column group level.

Suppress

Select true to suppress the subtotal for a column field.

OK

Select to apply any changes you made here and close the dialog box.

Cancel

Select to close the dialog box without saving any changes.

Help button

Select to view information about the dialog box.

Close button

Select to close the dialog box without saving any changes.
