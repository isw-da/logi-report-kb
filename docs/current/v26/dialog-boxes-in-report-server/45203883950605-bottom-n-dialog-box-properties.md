# 
Bottom N Dialog Box Properties

You can use the Bottom N dialog box to filter data to display the Bottom N values. This topic describes the properties in the dialog box.

Value

Type a positive integer number N if you want to display the bottom N values.

OK

Select to display the bottom N values.

Cancel

Select to close the dialog box without saving any changes.

Help

Select to view information about the dialog box.
