# 
Select Values Dialog Box Properties

This topic describes how you can use the Select values dialog box to set the current selected value for filter control.

Server displays the dialog box when click you click the button for the currently selected value on the inspector:

Available Values

Display the current available values.

You can select multiple values at a time and click add button to add them to Selected Values.

- 
Selected ValuesDisplay the current selected values.

For values you do not want, select them in the Selected Values box and click the remove button remove them.

- 
Enter Values
You can type a value manually and select the button Add Values next to add it to the Selected Values box.

- 
Cancel Select to close the dialog box without change value.

- 
OKSet the current selected value for filter control and close the dialog box.

Close button

Select to close the dialog box without change value.
