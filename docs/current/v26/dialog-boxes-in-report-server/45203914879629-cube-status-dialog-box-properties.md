# 
Cube Status Dialog Box Properties 

You can use the Cube Status dialog box to view the information about whether the data components in the current dashboard apply in-memory cubes and the reasons if not. This topic describes the properties in the dialog box.

Server displays the dialog box after you select the Cube Status button  on the toolbar. 

Component

The data components in the current dashboard.

Business View

The business view each data component uses. 

Data Source

The catalog data source that contains the business view.

Catalog

The path and name of the catalog that contains the data source.

Cube Status

Server shows whether a data component applies an in-memory cube. This column is sortable.

Reason

The reason why a data component does not apply an in-memory cube. The contents may not display fully, in which case you can hover over a reason to get its complete contents.

OK

Select to close the dialog box. 

Help button

Select to view information about the dialog box.

Close button

Select to close the dialog box.
