# 
Web Action - Sort Dialog Box Properties 

Use the Web Action - Sort dialog box to edit the sort condition to sort a data component when it receives a synchronization message. This topic describes how to define the sort condition.

Server displays the dialog box when you select the web action *Sort and select the Edit button  in the Actions column of the Receive Sync dialog box.

Add button

Select to add a new sorting criterion.

Remove button

Select to remove the selected sorting criterion.

Sort On

Select the column you want to sort.

Sort Value

Select the value of how you want to sort on the column.

OK

Select to apply any changes you made here and close the dialog box.

Cancel

Select to close the dialog box without saving any changes.

Help button

Select to view information about the dialog box.

Close button

Select to close the dialog box without saving any changes.
