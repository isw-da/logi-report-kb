# 
Bookmark Dialog Box Properties

This topic describes how you can use the Bookmark dialog box to bookmark the current web report or update a bookmark. 

Server displays the dialog box when you select the Save Bookmark button  on the toolbar in Web Report Studio or Details in the Bookmark Setting dialog box.

Parameter

Parameters that the report uses.

Dataset Filter

Filters that you created via the Edit Dataset Filter dialog box. 

Browser Filter

Filters that you created via the Filter dialog box.

Drill Filter

Go-to filters that you created when performing the go-to-by-value action on the report. 

On-screen Filter

Filters that you created via the Filter panel and filter controls.

Name

Specify the name for the bookmark.

Description

Provide a description for the bookmark.

OK

Select to apply any changes you made here and close the dialog box.

Cancel

Select to close the dialog box without saving any changes.

Help button

Select to view information about the dialog box.

Close button

Select to close the dialog box without saving any changes.
