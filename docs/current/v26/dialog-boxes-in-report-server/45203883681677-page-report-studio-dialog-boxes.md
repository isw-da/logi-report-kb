 The object properties dialog boxes might be different for an advanced user and for a normal user. An advanced user can modify some properties that a common user cannot, and can use formulas to control properties. The  properties dialog boxes in this topic are based on an advanced user.

To enable advanced user in the server profile:

- On the system toolbar of the Server Console, navigate to the My Profile > Customize Profile page.
            

- Select Customize Profile. Server displays the Customize Profile dialog box.
            

- Select Enable Customize Properties.
            

- Navigate to the Page Report Studio > Advanced tab.
            

- Select  Advanced User.

- Select OK to accept the change.
