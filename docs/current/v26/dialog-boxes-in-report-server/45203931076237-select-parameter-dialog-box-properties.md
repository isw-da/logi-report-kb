# 
Select Parameter Dialog Box Properties 

Use the Select Parameter dialog box to insert a parameter into the URL of the web page that you want to add to a dashboard. This topic describes how to select a parameter.

Server displays the dialog box when you select Add Parameter in the Insert URL Frame dialog box or Edit URL Frame dialog box if you have specified a data source, or select a data source and select OK in the Select Data Source dialog box.

Parameters  

Server lists the available parameters in the data source. Select one to insert into the URL.

Change Data Source 

Select to open the Select Data Source dialog box to use another data source.

OK

Select to insert the selected parameter into the URL.

Cancel

Select to close the dialog box without saving any changes.

 Help button

Select to view information about the dialog box.

 Close button

Select to close the dialog box without saving any changes.
