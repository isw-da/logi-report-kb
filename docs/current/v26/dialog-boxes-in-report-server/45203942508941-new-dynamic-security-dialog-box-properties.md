# 
New Dynamic Security Dialog Box Properties

This topic describes how you can use the New Dynamic Security dialog box to create dynamic catalog security. 

Server displays the dialog box when an administrator selects New Dynamic Security in the Administration > Security > Dynamic Security page on the Server Console.

Catalog

Specify the catalog you want to create dynamic security for.

Type the catalog with the full resource path in the text box, for example, /SampleReports/SampleReports.cat, or select Browse to select a catalog in the Select Catalog dialog box.

Security File

Specify the security file that you generated in Report Designer, to create dynamic security for the catalog. Select Browse to select a catalog security file, which defines business view security, record level security, and column level security in the catalog.

OK

Select to create the dynamic security and exit the dialog box.

Cancel

Select to close the dialog box without creating the dynamic security. 

Help

Select to view information about the dialog box.
