# 
Excel Encrypt Dialog Box Properties

This topic describes how you can use the Excel Encrypt dialog box to specify the Excel encryption properties while configuring settings for advanced running/publishing a report in Excel.

- 
Read-only
    Select if you want to export the Excel document as read-only.

- 
Password to open
Specify the password for opening the Excel document, to prevent others from opening it without authorization.

- 
Confirm Password to open
Type the password again to confirm it.

- 
Password to modify
Specify the password for modifying the Excel document, to prevent others from editing it without authorization. The password you specify here cannot be the same as the one you use to open the document.

- 
Confirm Password to modify
Type the password again to confirm it.

- 
OK
Select to apply any changes you made here and close the dialog box.

- 
Cancel
Select to close the dialog box without saving any changes.
