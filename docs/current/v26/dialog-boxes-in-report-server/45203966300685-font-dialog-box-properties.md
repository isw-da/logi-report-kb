# 
Font Dialog Box Properties

This topic describes how you can use the Font dialog box to specify the font format of a label or field. Server displays the dialog box when you select a label or field and select the Font button  on the toolbar.

Font

Specify the font face.

Size

Specify the font size.

Color

Specify the font color. To change the color, select the color indicator. Server displays the color palette. Select a color, or select More Colors to access the Color Picker dialog box in which you can specify a color within a wider range.

Select if you want to make the object bold. 

Select if you want to make the object italic.

Select if you want to underline the object.

Preview

Server shows an example of the font effect.

OK

Select to apply any changes you made here and close the dialog box.

Cancel

Select to close the dialog box without saving any changes.

Help button

Select to view information about the dialog box.

Close button

Select to close the dialog box without saving any changes.
