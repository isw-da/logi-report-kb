# 
Running and Scheduling ReportsReport Server v26

On the Server Console, you can run or schedule the reports that you published or saved into the resource tree, in a variety of formats. This topic describes how you can run and schedule to run reports and specify parameter values to reports.

When running a report, you can use either direct running or advanced running. Scheduling  a report enables you to deliver a report to different destinations in various formats at one or more designated dates and times. Report Server records the report running tasks in different task tables. You can view the status of these tasks, such as scheduled tasks that are waiting to run, the tasks that are currently running, and the tasks that have already finished running in different task tables.

You can also use URL commands to directly run reports and schedule report tasks. For more information, see Running Reports via URL and Scheduling Reports via URL.

Tip: You can customize the Resources page on the Server Console to suit your requirements by setting your own preferences. To do this:

- Select Tools > Preferences on the task bar of the Resources page.

- In the General tab of the Preferences page, specify the default viewing format when directly running a report, and set which columns to show in the resource information table.

- In the Export Formats tab, predefine the properties for each export format which will be applied when you run or schedule a report.

- Select OK to apply the settings. Server saves the specified default report viewing format and export properties into the server profile.
