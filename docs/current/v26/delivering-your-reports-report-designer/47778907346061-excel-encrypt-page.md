# 
Excel Encrypt Page

You can use the Excel Encrypt dialog box to configure the encryption settings for an Excel document. 

This topic describes the options in the dialog box.

Designer displays the Excel Encrypt dialog box when you select the Setting button after selecting the Encrypt checkbox in the Export to Excel dialog box.

- 
Read-only
    Select to export the Excel document as read-only.

- 
Password to open
Specify the password to prevent users from opening the document without authorization.

- 
Confirm Password to open
Confirm the password you specified in the Password to open text box.

- 
Password to modify
Specify the password to restrict users from modifying the Excel document. The modify password should be different from the one used for opening the document.

- 
Confirm Password to modify
Confirm the password you specified in the Password to modify text box.

- 
OK
Select to apply any changes you made here and close the dialog box.

- 
Cancel
Select to close the dialog box without saving any changes.
