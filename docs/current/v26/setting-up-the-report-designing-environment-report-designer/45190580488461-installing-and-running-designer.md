# 
Installing and Running Designer

Designer can run on Windows, macOS, UNIX, and Linux platforms. This topic introduces installing and running Designer on different platforms using different methods. It also describes how you can update your Designer license key without reinstalling it, configure the Report logging system, and predefine proxy settings when you need to connect to  a REST Web Service in a restricted network.

 You need to choose a Java Development Kit (JDK) to install Designer. Report supports the Oracle JDK and OpenJDK versions as stated in System Requirements. If you need more information, contact Customer Service.
