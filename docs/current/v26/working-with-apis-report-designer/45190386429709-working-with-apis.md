# Working with APIs

APIs provide a way to build Report components and services into other applications, thus integrating Report with existing platform infrastructure. This topic is aimed at Java developers who want to understand how Report works, and how to write Java code that uses the APIs effectively.

The comprehensive Javadoc matrix covering all the classes and methods of the APIs is available in the Report Java API Documentation. This topic is an introduction and overview of the APIs so that the vastness of the Java docs is easier to master. Beyond that are explanations of use cases, with examples of code.
