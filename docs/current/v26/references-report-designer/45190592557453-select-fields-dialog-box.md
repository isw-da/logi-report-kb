# 
Select Fields Dialog Box

You can use the Select Fields dialog box to select the fields according to whose unique values to calculate DistinctSum. This topic describes the options in the dialog box.
    

Designer displays the Select Fields dialog box when you select DistinctSum as the aggregate function of an object and select the ellipsis  to set the Distinct On option, or right-click one or more aggregations in a crosstab and on the shortcut menu select DistinctSum from the Switch Aggregate Function submenu.

Designer displays these options:

Resources

This box lists all the available data resources that you can add to calculate DistinctSum.

Add button

Select to add the specified fields in the Resources box for calculating DistinctSum.

Remove button

Select to remove the specified fields from the Distinct On box.

Distinct On

This box lists the fields according to whose unique values you add to calculate DistinctSum.

OK

Select to apply your settings and close the dialog box.

Cancel

Select to close the dialog box without saving any changes.

Help

Select to view information about the dialog box.
