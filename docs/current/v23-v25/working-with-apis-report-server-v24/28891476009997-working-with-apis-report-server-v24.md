# 
Working with APIsReport Server v24

APIs provide a way to build Report components and services into other applications, thus integrating Report with existing platform infrastructure. This topic helps Java developers understand how Report works, and how to write Java code that uses the APIs effectively.

The comprehensive Java doc matrix covering all the classes and methods of the APIs is available in the Report Javadoc. This topic is an introduction and overview of the APIs so that the vastness of the Java docs will be easier to master. Beyond that are explanations of use cases and code examples.
