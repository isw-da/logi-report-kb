# 
Add Collection Dialog Box

You can use the Add Collection dialog box to add more schemas into a catalog via the MongoDB connection you set up. This topic describes the options in the dialog box.
    

Designer displays the Add Collection dialog box when you right-click the Schemas node or a database node in the Schemas node of a MongoDB connection and select Add Collection on the shortcut menu in the Catalog Manager.

Designer displays these options:

Collections

- If you open the dialog box by right-clicking the Schemas node, the box lists the collections in all databases that you can access.

- If you open the dialog box by right-clicking a database node, the box lists the collections in this database.

Select the collections you want to transform to relational schemas in the box. 

Added Schemas

This box lists the schemas to be added to the catalog, which Designer transforms from the collections you select.

Add button

Select to add the specified collections in the Collections box to transform to relational schemas. 

Remove button

Select to remove the specified schemas from the Added Schema box.

OK

Select to add the schemas transformed from the specified collections to the catalog.

Cancel

Select to close the dialog box without saving any changes.

Help

Select to view information about the dialog box.
