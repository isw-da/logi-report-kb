# 
User Defined Function Properties

This topic describes the properties of a User Defined Function (UDF) object in a catalog.

| Property Name | Description |
| --- | --- |
| Expression | Shows the whole statement of the function. Read only. |
| Name | Specifies the mapped name of the object in the catalog. Data type: String |
| SQL Type | Specifies the SQL type of the object defined in Java. Choose an option from the drop-down list. Data type: Integer |
