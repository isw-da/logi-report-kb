# 
Go Down Dialog Box

You can use the Go Down dialog box to define a Go Down web action for the specified data component in a library component as a response to the user-defined message it receives at runtime. This topic describes the options in the dialog box.
    

Designer displays the Go Down dialog box when you select *Go Down and select OK in the Web Action List dialog box.

Designer displays these options:

Add button

Select to add a new condition line. You can add one condition line at most. 

Remove button

Select to delete the condition.

Move Up button

Designer does not enable this button for building the Go Down web action.

Move Down button

Designer does not enable this button for building the Go Down web action.

Go Down On

Specify the group on which to perform the go-down action.

Use Hierarchy

Specify the hierarchy for the go-down action to follow. 

By Value

Specify by which value of the specified group to perform the go-down action, that is to perform the go-down action with the filter condition SpecifiedGroupField=TheValue.

OK

Select to apply your settings and close the dialog box.

Cancel

Select to close the dialog box without saving any changes.

Help

Select to view information about the dialog box.
