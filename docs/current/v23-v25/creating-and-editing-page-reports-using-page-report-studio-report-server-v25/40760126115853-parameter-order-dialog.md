# 
Parameter Order Dialog

You can use the Parameter Order dialog to adjust the display sequence of the parameters in the UI for specifying parameter values at report level. This topic describes the options in the dialog box.

Page Studio displays the Parameter Order dialog when you navigate to Menu> Report> Parameter Order in Basic View Mode.

Page Studio displays these options:

Parameters

This box lists all the parameters used by the open report. To adjust the display sequence of the parameters, use the Move Up and Move Down buttons.

Reset

Select it to reset the parameter order.

Move Up

Select to move the specified parameter higher in the list.

Move Down

Select to move the specified parameter lower in the list.

OK

Select to apply your settings and close the dialog.

Cancel

Select to close the dialog without saving any changes.
