# Working with Maps

A map is a special kind of image in Report. This topic introduces the usages of the two types of maps Report supports: Geographic Map and Shape Map.

- 
Geographic map is a data component integrated with Google Maps, OpenStreetMap, or OpenCycleMap.

- 
Shape map contains a picture and certain areas that are bound with groups in a banded object.
