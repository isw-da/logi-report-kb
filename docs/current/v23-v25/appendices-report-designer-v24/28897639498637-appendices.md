# 
Appendices

The Report Designer Help System has the following appendices:

- Appendix 1: Formula Functions

- Appendix 2: Formula Operators

- Appendix 3: Parameters of User-Defined Web Actions

The purpose of these appendices is to make the use of Report Designer much easier and more convenient by introducing you to the types of formula functions and operators, and the parameter values required for building user-defined web actions.
