# 
Edit Link Dialog Box Properties

This topic describes how you can use the Edit Link dialog box to edit the link on the selected object. Server displays the dialog box when you select an object which has a link, right-click it, and select Edit Link on the shortcut menu.

OK

Select to apply any changes you made here and close the dialog box.

Cancel

Select to close the dialog box without saving any changes.

Help button

Select to view information about the dialog box.

Close button

Select to close the dialog box without saving any changes.

For information about the other properties in the dialog box, see Insert Link Dialog Box Properties.
