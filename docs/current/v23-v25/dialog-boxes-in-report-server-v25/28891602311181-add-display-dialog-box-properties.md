# 
Add Display Dialog Box Properties

Use the Add Display dialog box to add available display text keys in the specified resource for editing NLS. This topic describes how to add display text keys.

Server displays the dialog box when an administrator selects  the Add button  in the Display tab of the NLS Editor.

Available Display

Server lists all the available display text keys in the specified catalog/report/library component.

Select the display text keys that you want to add. Select the checkbox on the column header to select all the keys. 

Search box

Type a keyword, and then select the Search icon  or press Enter to start searching.

Type

Type of display text for different objects. You can select the column header to sort the items by type in the ascending or descending order.

Key

Key indicates objects in original language. You can select the column header to sort the items by key in the ascending or descending order.

Translate

Translate the keys in the target language. You can select the column header to sort the items by translation in the ascending or descending order.

OK

Select to add the selected keys to the Display tab of the NLS Editor. 

Cancel

Select to close the dialog box without adding keys.

Reset

Select to reset the dialog box to its initial status. 

Help

Select to view information about the Add Display dialog box.
