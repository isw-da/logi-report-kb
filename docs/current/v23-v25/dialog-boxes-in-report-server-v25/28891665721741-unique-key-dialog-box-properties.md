# 
Unique Key Dialog Box Properties 

Use the Unique Key dialog box to specify a unique key to ensure there are no duplicated records in the real time chart or library component. This topic describes how to select the unique key.

Server displays the dialog box when you select Incremental Fetch in the Real-time Settings dialog box or select the ellipsis button  beside the Unique Key text box in the Auto Refresh dialog box.

Resources

Server lists the elements in the business view that the real time chart or library component uses.

Add button

Select to add the selected fields to the Unique Key box.

Remove button

Select to remove the selected fields from the Unique Key box if you do not want them.

Unique Key

Server lists the fields you have added as the unique key, which is to guarantee there are no two records with the same unique key value in the real time chart or library component.

OK

Select to apply any changes you made here and close the dialog box.

Cancel

Select to close the dialog box without saving any changes.

Help button

Select to view information about the dialog box.

Close button

Select to close the dialog box without saving any changes.
