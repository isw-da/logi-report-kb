# 
Aggregate On Dialog Box Properties

You can use the Aggregate On dialog box to summarize data in the selected table detail column. This topic describes the properties in the dialog box.

Server displays the dialog box when you do either of the following:

- Right-click the field in a table detail column and select Aggregate On from the shortcut menu. 

- Select a column header to select the column, then on the toolbar select the Aggregate On button . 

Aggregate On

Server displays the field bound with the detail column. The field is also the one on which the summary is based. 

Function 

Select the function for summarizing the field in the detail column.

Distinct On

       Server enables this property when you select DistinctSum as the aggregate function, and you should set it. Select the ellipsis button , and then in the Select Fields dialog box select the fields according to whose unique values you want to calculate the DistinctSum function.    

OK

Select to summarize the detail column data with the specified function and exit the dialog box.

Cancel

Select to close the dialog box without saving any changes.

 Help button

Select to view information about the dialog box.

 Close button

Select to close the dialog box without saving any changes.
