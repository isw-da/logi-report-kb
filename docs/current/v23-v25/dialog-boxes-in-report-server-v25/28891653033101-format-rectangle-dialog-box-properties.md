# 
Format Rectangle Dialog Box Properties

This topic describes how you can use the Format Rectangle dialog box to customize the line properties of the rectangle separator of the specified group in a heat map. Server displays the dialog box when you right-click on a heat map, select a group field from the Format Rectangle submenu. 

Color

Specify the color of the separator.

Transparency

Specify the transparency for the color of the separator.

Line Style

Specify the line style of the separator.

Thickness

Specify the thickness of the separator, in pixels.

OK

Select to apply any changes you made here and close the dialog box.

Cancel

Select to close the dialog box without saving any changes.

Help button

Select to view information about the dialog box.

Close button

Select to close the dialog box without saving any changes.
