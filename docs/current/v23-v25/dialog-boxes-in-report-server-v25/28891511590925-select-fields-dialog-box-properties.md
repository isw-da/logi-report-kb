# 
Select Fields Dialog Box Properties

You can use the Select Fields dialog box to select the fields according to whose unique values you want to calculate the DistinctSum function. This topic describes the properties in the dialog box.

Server displays the dialog box when you do one of the following:

- Select DistinctSum from the Aggregate Function or Function list, and then select the ellipsis button  next to the Distinct On text box in the Add Aggregation dialog box, Insert Aggregation dialog box, or Aggregate On dialog box. 

- In the Data tab of the Crosstab Wizard,  Insert Crosstab dialog box, or Convert to Crosstab dialog box, or in the To Crosstab dialog box, select DistinctSum from the Aggregate list, and then select the ellipsis button  next to the Distinct On text box.

- Right-click an aggregation that is based on a detail object in a crosstab, and then select Switch Function > DistinctSum on the shortcut menu.

Resources

Server lists the group and detail objects in the current business view. For a crosstab, it lists only the detail objects. Select a field and select the Add button  to add it to the right box.

Distinct On

Server lists the fields according to whose unique values you want to calculate the DistinctSum function. To remove a field, select it and then select the Remove button .

OK

Select to apply the selected fields and close the dialog box.

Cancel

Select to close the dialog box without saving any changes.

 Help button

Select to view information about the dialog box.

 Close button

Select to close the dialog box without saving any changes.
