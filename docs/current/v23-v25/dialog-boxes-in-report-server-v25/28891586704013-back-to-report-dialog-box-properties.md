# 
Back to Report Dialog Box Properties

You can use the Back to Report dialog box to specify whether to display full report data and return to Page Report Studio. This topic describes the properties in the dialog box.

Server displays the dialog box when you select the Return button .

Full Data

Select if you want to display full data in the report.

Partial Data

Select if you don't want to display full data in the report. Then, specify the number of data records you want to display in the report.

Cancel

Select to close the dialog box and stays in Report Studio.

OK

Select to return to Page Report Studio and display the report with full data or partial data.

Help button

Select to view information about the  dialog box.

Close button

Select to close the dialog box and stays in Report Studio.
