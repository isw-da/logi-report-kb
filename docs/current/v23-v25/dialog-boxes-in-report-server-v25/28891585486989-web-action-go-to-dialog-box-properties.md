# 
Web Action - Go To Dialog Box Properties 

Use the Web Action - Go To dialog box to edit the go-to condition to change one field to another in a data component when it receives a synchronization message. This topic describes how to define the go-to condition.

Server displays the dialog box when you select the web action *Go To and select the Edit button  in the Actions column of the Receive Sync dialog box.

Go To On

Select a field on which you want to perform the go-to action in the data component.

To Column 

Select a field to change the Go To On field to.

By Value

Select By Value if you want to perform the go-to action by filtering a value of the Go To On field and then select the value. Server disables it if you select a crosstab aggregate field as the Go To On field.

OK

Select to apply any changes you made here and close the dialog box.

Cancel

Select to close the dialog box without saving any changes.

Help button

Select to view information about the dialog box.

Close button

Select to close the dialog box without saving any changes.
