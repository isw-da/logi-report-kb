# 
Insert Special Field Dialog Box Properties 

Use the Insert Special Field dialog box to insert a special field in the dashboard header. This topic describes how to select a special field.

Server displays the dialog box when you drag Special Field from Toolbox in the Resources panel to the dashboard header.

- 
User Name
    The username that you use to sign in to Report Server.

- 
Modified Date
    The date when you modified the dashboard last time.

- 
Modified Time
    The time when you modified the dashboard last time.

- 
Print Date
    The current system date of your computer.

- 
Print Time
 The current system time of your computer.

OK

Select to insert the selected special field in the dashboard header.

Cancel

Select to close the dialog box without the insertion.

Help button

Select to view information about the Insert Special Field dialog box.

Close button

Select to close the dialog box without the insertion.
