# 
National Language Support 

Report products implement a National Language Support (NLS) feature, with which you can run Report Server, including Page Report Studio, Web Report Studio, JDashboard, and Visual Analysis, and reports in different language environments.

You can also edit NLS in Report Designer. For more information, see Applying National Language Support in the Report Designer Guide.
