# 
Start Page

When you open Designer, by default, you get the Start Page which provides some quick entries to the key functions of Designer. If you do not want to display the page, you can select Do not show this page at start up at the bottom left of the page. You can open the Start Page at any time by selecting Quick Start at the top right corner of the Designer main window. This topic introduces the function entries available on the Start Page. 

How To

This category guides you to access the Report Feature Guide and Tutorial, and to open the demos  on the Report website. 

Connect

This category lists the most popular connection types. You can select any one to set up a corresponding connection to connect your database with a catalog. The More Connections item directs you to a full list of the connection types Report supports.

Create

You can create a page report, web report, or library component by selecting the link in the category. Designer creates the report into the catalog that was in use when you exited Designer the last time. 

Open

You can browse to open a report in Designer. The recently opened reports are also listed. You can select any one to open it directly.

Other

Three more links that direct you to the Designer User's Guide, and to the home page and technical support on the Report website.
