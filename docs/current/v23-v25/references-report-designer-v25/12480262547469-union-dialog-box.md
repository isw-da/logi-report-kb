# 
Union Dialog Box

You can use the Union dialog box to create a union for a query in the catalog or for the underlying query of a business view. This topic describes the options in the dialog box.
    

Designer displays the Union dialog box when you select Menu > Query > Union > Select in the Query Editor dialog box.

Designer displays these options:

Queries

This box lists the queries in the current catalog that you can combine in the union. When you are creating the union for a business view, also the BV queries of this business view.

Add button

Select to add the specified query to the union.

Remove button

Select to remove the specified query from the union.

Union

This box lists the queries you add to combine in the union.

- 
Attribute
This column shows the attribute you specify for the queries in the union.
- 

Select to not return duplicate records from the query.

- 

Select to return all records from the query.

- 
Name
This column displays the names of the queries.

OK

Select to apply your settings and close the dialog box.

Cancel

Select to close the dialog box without saving any changes.

Help

Select to view information about the dialog box.
