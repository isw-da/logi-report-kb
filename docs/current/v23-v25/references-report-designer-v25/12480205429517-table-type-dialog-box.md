# 
Table Type Dialog Box

You can use the Table Type dialog box to choose a type for the table you want to create. This topic describes the options in the dialog box.
    

Designer displays the Table Type dialog box when you navigate to Insert > Table.

Designer displays these options:

Table (Group Above)

Select to create a table which displays group information above the detail row.

Table (Group Left)

Select to create a table which displays group information left to the detail row.

Table (Group Left Above)

Select to create a table which displays group information left above the detail row.

Summary Table

Select to create a table which displays only group and summary information.

OK

Select to open the Create Table dialog box to create the table and close the dialog box.

Cancel

Select to close the dialog box without saving any changes.

Help

Select to view information about the dialog box.
