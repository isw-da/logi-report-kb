# 
Insert Tabular Dialog Box

You can use the Insert Tabular dialog box to insert a tabular into a report. This topic describes the options in the dialog box.
    

Designer displays the Insert Tabular dialog box when you navigate to Insert > Tabular, or drag the Tabular icon  from the Components panel to the destination.

Designer displays these options:

Rows

Specify the number of rows to create in the tabular.

Columns

Specify the number of columns to create in the tabular.

Width

Specify the width of the tabular.

Border

Specify the length for the border of the tabular.

OK

Select to insert the tabular into the report and close the dialog box.

Cancel

Select to close the dialog box without saving any changes.

Help

Select to view information about the dialog box.
