# Insert TOC Page Dialog Box

You can use the Insert TOC Page dialog box to add a table of contents in a page or web report. This topic describes the options in the dialog box.
    

Designer displays the Insert TOC Page dialog box when you navigate to Insert > TOC Page, or  right-click in any blank area in a page panel and select Insert > TOC Page from the shortcut menu.

Designer displays these options:

Keep Current Page Setting

Select to add the TOC with current page settings.

Use New Page Setting

Select to add the TOC with new page settings.

OK

Select to add the TOC with current page settings, or open the Page Setup dialog box to specify page settings for the new TOC pages.

Cancel

Select to close the dialog box without saving any changes.

Help

Select to view information about the dialog box.
