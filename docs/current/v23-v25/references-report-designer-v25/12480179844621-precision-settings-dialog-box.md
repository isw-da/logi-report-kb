# 
Precision Settings Dialog Box

You can use the Precision Settings dialog box to predefine the precision level at which you want to export reports to different formats. This topic describes the options in the dialog box.
    

Designer displays the Precision Settings dialog box when you select System Default Settings in the Advanced Export Settings dialog box.

Designer displays these options:

- 
High
Select to export the report  to the specified format with high precision.

- 
Low
Select to export the report  to the specified format with low precision.

OK

Select to apply your settings and close the dialog box.

Cancel

Select to close the dialog box without saving any changes.

Help

Select to view information about the dialog box.
