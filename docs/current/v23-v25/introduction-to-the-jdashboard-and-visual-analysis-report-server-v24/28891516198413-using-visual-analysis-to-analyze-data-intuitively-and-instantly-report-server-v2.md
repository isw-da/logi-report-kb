# 
Using Visual Analysis to Analyze Data Intuitively and InstantlyReport Server v24

Report Visual Analysis is an in-context analysis tool to visualize the result of every step of your work. This topic describes the main features, the data sources which are business views, and the license of Visual Analysis.

You can easily transform data into rich visualizations simply by dragging and dropping data fields onto a layout module. You can also view and analyze data from different perspectives and discover more actionable intelligence. 

Visual Analysis has the following main features:

- Using groups & aggregations to quickly highlight colors, sizes & shapes

- Instantly change data visualizations with over 50 options

- Powerful in-memory cube technology

Business views are the data sources used in Visual Analysis. Each time you can perform data analysis based on one business view, and later you can save the result as an analysis template into the server resource tree. However, Visual Analysis does not support the customization of parameter values, so if a business view contains parameters, the default parameter values will be applied when you perform visual analysis on the business view.

Visual Analysis is a separately licensed feature of Report Server. It is installed together with Report Server so only the license key needs to be updated to enable it to run. For more product information, including new purchases and upgrades, contact US Sales or UK Sales.

You can also use URLs to start Visual Analysis and work on it. For more information, see Accessing Visual Analysis via URL.

If Visual Analysis cannot work well on your Google Chrome, you can try disabling GPU accelerated 2D canvas: access the URL chrome://flags, disable accelerated 2D canvas, and then relaunch Chrome.
